# OpenEA v1 — Production Evidence Bridge (Phase C, Patch 03)

## Purpose

This layer connects already-computed OpenEA evidence to the Phase-B scientific
contracts. It does **not** run quantum chemistry and does not replace the
existing Stage-2/Stage-3 execution machinery.

The first implementation is deliberately the **single-reference production
branch**. It consumes a Reference Character Gate result plus existing
cardinal/diffuse/CBS/core-valence/scalar-relativity/post-CC evidence and builds:

- G3a--G3e reviews;
- a component-resolved `EAEstimate` and `ErrorBudget`;
- explicit gate-closure actions;
- precision-refinement planning only after the scientific gates are closed.

A multireference production route must use a separate MR evidence bridge. Even
an explicitly validated MR capability must **not** reuse a CCSD(T)/CBS baseline
through this module.

## Canonical single-reference baseline

The current bridge uses the existing component-resolved CCSD(T)/CBS result as
the electronic valence baseline. The central value is
`ea_cbs_plus_diffuse_primary_ev`.

Its uncertainty is decomposed instead of collapsed into one opaque number:

- CBS model sensitivity -> baseline offset;
- diffuse residual -> separate uncertainty component;
- fixed-geometry / PEC transfer check -> separate uncertainty component.

If either residual is unavailable, it is represented as `UNKNOWN`; it is never
silently replaced by zero.

## Additive corrections

The bridge currently knows how to translate:

- core-valence assessment;
- one-electron SFX2C1E scalar-relativistic assessment;
- optional CCSDT `DeltaT3` diagnostic/correction.

Additional physical corrections are supplied through explicit correction
evidence objects. The default production inventory deliberately leaves these
open until evidence exists:

- residual scalar-relativistic physics beyond one-electron SFX2C1E;
- spin-orbit coupling;
- nuclear motion.

A correction can close only by either:

1. carrying a bounded additive interval with provenance; or
2. being explicitly `NOT_APPLICABLE` with a physical rationale.

## Post-CC behavior

CCSDT remains a diagnostic.

```text
small + stable DeltaT3
    -> G3c may close
    -> optional bounded POST_CC correction may enter the error budget

large / unstable DeltaT3
    -> POST_CC_WARNING
    -> G3c open
    -> G3a reopened
    -> REASSESS_REFERENCE_CHARACTER
```

No T4/CCSDTQ action is generated by this bridge.

## BORDERLINE references

A `BORDERLINE` reference requires both:

- cleared expanded reference diagnostics (G3a); and
- an explicit `REFERENCE_CHARACTER` uncertainty component in the error budget
  (G3e).

The second requirement is not satisfied merely because the numerical budget is
otherwise complete.

## Planning order

Production planning is fail-closed and ordered as:

```text
Reference Character route
        |
        v
G3 gate closure actions
        |
        v
closed production interval/error budget
        |
        v
Precision Controller
        |
        +-- target met -> no extra expensive work
        |
        +-- target missed + valid useful action -> recommend refinement
        |
        +-- target missed + no valid action -> scientific decision still allowed
```

Missing a requested precision target does not become `UNRESOLVED` by itself.

## Scope boundary

This patch intentionally does **not** implement:

- SOC production calculations;
- nuclear-motion production calculations;
- a multireference energy-evidence bridge;
- automatic execution of recommended calculations;
- a final end-to-end `BOUND / UNBOUND / UNRESOLVED` orchestration layer.

Those remain later architecture work. The purpose of this patch is to make the
existing numerical evidence enter the new scientific contracts without
molecule-specific assumptions or silent missing-physics zeros.
